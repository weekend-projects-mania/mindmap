

# Mindmap Web App

A split-screen mindmap application for organizing thoughts and notes, with all data stored locally in your browser.

---

## Core Layout

**Split-screen interface** with a resizable divider:
- **Left panel**: Interactive mindmap canvas with the node graph
- **Right panel**: Rich WYSIWYG markdown editor for the selected node's content
- Clean, minimal design with subtle borders and shadows

---

## Mindmap Features

**Graph visualization**:
- Top-down tree layout with the main topic at the top
- Visual connection lines between parent and child nodes
- Smooth animations when nodes are added, moved, or collapsed

**Node interactions**:
- Click to select a node and view/edit its content
- Drag and drop to rearrange nodes or change parent relationships
- Zoom in/out with scroll wheel and pan by dragging the canvas
- Collapse/expand nodes to hide or show their children
- Add new child nodes with a simple "+" button on hover
- Delete nodes with confirmation

---

## Content Editor

**Rich WYSIWYG markdown editor**:
- Toolbar with formatting buttons (bold, italic, headers, lists, links, code blocks)
- Real-time rendering as you type
- Support for standard markdown syntax
- Node title displayed above the editor

---

## Mindmap Management

**Multiple mindmaps**:
- Sidebar or dropdown to switch between different mindmaps
- Create new mindmaps with a name/title
- Rename and delete existing mindmaps
- Each mindmap has its own root node and tree structure

---

## Data Storage

**Browser local storage**:
- All mindmaps, nodes, and content saved automatically
- Persists between browser sessions
- No account or backend required

---

## Visual Design

**Clean & minimal aesthetic**:
- Light gray backgrounds with subtle shadows
- Clear typography for readability
- Rounded node shapes with clean connecting lines
- Responsive and professional look
